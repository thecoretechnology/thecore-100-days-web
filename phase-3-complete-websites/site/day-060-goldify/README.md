# Day 060 — Goldify

Goldify is a responsive, multi-page finance-product concept inspired by the visual language of premium gold-analysis platforms. It includes a cinematic home page, CSS-based market visualizations, feature dashboards, pricing, insights, a dedicated enquiry page, and accessible responsive navigation.

## Pages

- `index.html` — Home
- `about.html` — Purpose and product principles
- `features.html` — Capabilities and workflow
- `pricing.html` — Illustrative plans and comparison
- `insights.html` — Sample editorial perspectives
- `contact.html` — Dedicated enquiry form

The former contact popup has been removed. Contact calls-to-action now open the dedicated contact page.

## Run locally

From the repository root:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080/phase-3-complete-websites/site/day-060-goldify/
```

No installation or build step is required.

## Notes

- All market figures, plans, integrations and experience notes are illustrative sample content.
- This frontend demonstration does not provide financial advice, connect to live market data, or execute trades.
- The newsletter and enquiry forms validate in the browser but do not transmit data until a backend service is configured.
