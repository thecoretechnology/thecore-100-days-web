# VISORAA — Day 063

A multi-page contemporary art gallery website with individually art-directed pages: home, about, artists, artist profile, collections, exhibitions, exhibition detail, events, event detail, journal, journal article, contact, and 404.

## Run locally
From this folder, run `python3 -m http.server 8000` and open http://localhost:8000. No build step or package install is required.

## Notes
- HTML, CSS, and vanilla JavaScript; responsive layouts and reduced-motion support.
- Remote gallery photography and Google Fonts require internet access.
- Form submissions are front-end demo acknowledgements and do not send email or create real event reservations.
- Page content, editorial copy, exhibition details, artist profiles, and layouts are differentiated page-by-page.
