# Day 063 — Starlight Park

A multi-page Astro recreation of the Starlight Park Webflow reference, extended into a complete visitor website.

## Run locally

```bash
npm run dev
```

## Build for GitHub Pages

```bash
npm run build
```

The build command creates `dist/` and publishes the static result to this folder so GitHub Pages can serve it directly.

The enquiry form validates in the browser. Connect the marked integration point in `public/app.js` to a real form service before accepting live submissions.
