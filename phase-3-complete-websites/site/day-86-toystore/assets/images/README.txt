ToyStore local image assets
===========================

The products/ directory contains 16 locally bundled WebP toy product images. They were generated specifically for this recreation as replacement visuals because the original remote Webflow CDN files could not be downloaded in the build environment. They are not claimed to be the original copyrighted Webflow photographs.

The hero/ directory contains a locally assembled promotional collage made from the product images. The instagram/ directory contains distinct local product-photo crops.

All website image references now point to local files so product cards, product details, category banners, the promotional image, story background and Instagram tiles do not depend on the original external image CDN.
