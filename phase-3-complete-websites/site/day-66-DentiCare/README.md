# DentiCare Dental Website

Responsive multi-page dental clinic website inspired by the supplied reference screenshot.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Services (`services.html`)
- Team (`team.html`)
- Contact (`contact.html`)
- Service detail pages (open any service from `services.html` to view its dedicated detail layout)

## Run
Open `index.html` in a browser, or run a local server:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000

Features: responsive navigation, scroll reveals, animated orbiting hero treatment, floating tooth visual, hover tilt cards with CSS perspective, appointment/contact form interactions, screenshot-inspired service gallery, dedicated treatment detail views, reduced-motion support.

This is a front-end demo; the appointment form does not send data to a clinic backend.
