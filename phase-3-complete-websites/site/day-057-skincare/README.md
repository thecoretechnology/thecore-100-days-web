# AUREL — Multi-page Luxury Skincare Website

A responsive editorial skincare storefront built with semantic HTML5, CSS3 and vanilla JavaScript. The visual direction is inspired by premium beauty editorial sites, while the AUREL identity, logo and packaging are original.

## Pages
- `index.html` — Home and brand introduction
- `shop.html` — Product collection, category filters and shopping interactions
- `our-story.html` — Brand philosophy and ingredient approach
- `journal.html` — Editorial article index
- `article-vitamin-c.html`, `article-skin-type.html`, `article-routine.html` — Journal articles
- `contact.html` — Contact form, FAQs and support details

## Run locally
1. Extract the ZIP and open the `day 57 skincare` folder in VS Code.
2. Open `index.html` with VS Code Live Server.
3. Use the navigation to move between pages. An internet connection is needed for Google Fonts and selected editorial lifestyle photographs. Product packshots and logo assets are included locally.

## Functionality
- Shared shopping cart across pages, persisted in `localStorage`
- Add/remove products, quantity controls, live count and subtotal
- Quick view modal, product search and category filters
- Responsive navigation, back-to-top and scroll reveals
- Newsletter and contact form validation with demo success feedback
- Testimonial carousel on the homepage

## Brand identity
See `BRAND-GUIDE.md`. The primary AUREL logo uses the same botanical emblem + AUREL / SKINCARE lockup shown on the product packaging. SVG variants are editable and used in navigation, footer and favicon.

## Demo notice
This is a front-end portfolio demo. Checkout does not process payments or place orders. Newsletter and contact forms show local confirmation only and are not connected to a backend. Product details, prices and testimonials are illustrative.
