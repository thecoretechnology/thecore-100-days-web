# GAMEON — Day 064

A responsive, multi-page gaming experience inspired by the GameOn 128 Webflow template. This is an original implementation with original canvas arcade gameplay; it is not a pixel-perfect export of the paid template or its proprietary artwork.

## Included
- Home, Play Game, Games catalog, Game Details, About, Team, Blog, Contact, FAQ, custom 404
- Neon Rift browser arcade game: player movement, firing, enemy waves, collisions, health, collectible shards, level scaling, score and locally stored best score
- Keyboard controls (WASD/arrows, Space to fire, Esc to pause) and touch controls
- Functional search/filter, FAQ accordion, validated contact form success feedback
- Responsive UI and GSAP entrance transitions

## Run locally
1. Install Node.js 18+.
2. Open this directory in VS Code / terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Build
`npm run build`

External Unsplash photography and Google Fonts require internet connectivity. Game visuals are rendered with Canvas and work without external game assets.
